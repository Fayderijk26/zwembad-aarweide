# Zwembad Aarweide

Nieuwe website voor openluchtzwembad Aarweide in Nieuwveen.

Huidige versie: één zelfstandige `index.html` (HTML, CSS en JavaScript, geen build-stap).
De hero heeft een canvas-animatie van een bommetje met splash.

Openen: dubbelklik op `index.html`.

Inhoud en tarieven komen van https://www.zwembadaarweide.nl/ (seizoen 2026) en moeten voor 2027 worden bijgewerkt.
